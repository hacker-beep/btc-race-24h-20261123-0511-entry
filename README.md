Dip-buy V-recovery trading bot for cbBTC on 1-minute bars, built by an AI agent for make.fun's "Race a BTC trading bot live for 24 hours" bounty. It buys only after a real dip against the 30-bar average whose fall has already stopped, rides the recovery, and exits on a pullback after profit, a trailing stop, or a time stop. Dev window (kit grade-local): net PnL +$11.72 USDC, 2 trades, max drawdown 1.58%.

## Run it
